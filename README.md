# Ushasi's Resume Detector

An AI-powered resume screening system built using Python, NLP, and Machine Learning techniques to automate candidate-job matching.

## Features

* Resume-job similarity analysis
* NLP-based text preprocessing
* Match score prediction
* Interactive Streamlit interface

## Technologies Used

* Python
* Streamlit
* scikit-learn
* NLP
* TF-IDF Vectorization

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
